# คู่มือการใช้งานระบบสอบออนไลน์และแพลตฟอร์มการเรียนรู้
### Betong EduExam Platform | แผนกวิชาช่างอิเล็กทรอนิกส์ วิทยาลัยการอาชีพเบตง
**ผู้พัฒนาและผู้สอน:** นายณัฐชา ไชยหมาน | ภาคเรียนที่ 1 ปีการศึกษา 2569

## 🌟 1. ภาพรวมระบบ (System Overview)

ระบบสอบออนไลน์นี้ได้รับการออกแบบขึ้นมาเพื่อทดแทนการใช้ Google Forms แบบดั้งเดิม โดยเปลี่ยนเป็น **Modern Web Application** ที่ทำงานได้แบบ 100% Client-side ปลอดภัย รวดเร็ว รองรับการสอบทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ โดยมีจุดเด่นสำคัญ:
1. **บรรจุคลังข้อสอบครบทั้ง 5 รายวิชา** (รวม 175 ข้อปรนัย + 15 ข้ออัตนัย พร้อมเฉลยละเอียดและเกณฑ์ประเมิน)
2. **ระบบสุ่มข้อสอบและสุ่มตัวเลือก (Randomizer):** สลับลำดับข้อและตัวเลือก ก, ข, ค, ง อัตโนมัติเพื่อป้องกันการลอก
3. **ระบบป้องกันการทุจริต (Anti-Cheating Engine):** ตรวจจับการสลับแท็บ/ย่อหน้าจอ (Tab-switching & Blur detection) พร้อมบันทึกประวัติ (Audit Log) รายงานต่ออาจารย์
4. **ระบบบันทึกอัตโนมัติ (Instant Auto-save):** บันทึกคำตอบลงใน LocalStorage ทุกครั้งที่มีการเลือกคำตอบ หากเน็ตหลุดหรือเครื่องดับ สามารถเปิดกลับมาทำต่อได้ทันที
5. **มี 2 โหมดในตัวเดียว:**
   - 🔴 **โหมดสอบจริง (Official Examination):** จับเวลา 120 นาที ป้องกันทุจริต ตรวจคะแนนปรนัยทันที 30 คะแนน
   - 💡 **โหมดฝึกฝน/ติวข้อสอบ (Practice Mode):** แสดงผลถูก/ผิดทันที พร้อมคำอธิบายเฉลยละเอียดทุกข้อ เพื่อการเรียนรู้
6. **แดชบอร์ดครูผู้สอน (Teacher Admin Dashboard):** ดูผลสอบรายบุคคล สรุปสถิติ และส่งออกไฟล์ CSV ไปยังโปรแกรม Excel ได้ใน 1 คลิก
7. **เครื่องมือสร้าง Google Forms อัตโนมัติ:** แถมสคริปต์ Google Apps Script สำหรับกด Run สร้าง Google Forms ข้อสอบ 5 ชุดลงใน Google Drive ทันที

## 🚀 3. วิธีการเปิดใช้งานระบบ (How to Run)

### วิธีที่ 1: เปิดใช้งานแบบออฟไลน์ / ภายในห้องเรียนคอมพิวเตอร์ (ไม่ต้องต่ออินเทอร์เน็ต)
1. ดับเบิ้ลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ใดก็ได้ (Google Chrome, Microsoft Edge, Safari)
2. ใช้งานได้ทันที 100% โดยไม่ต้องติดตั้งโปรแกรมเสริมใด ๆ

### วิธีที่ 2: นำขึ้นใช้งานออนไลน์ฟรี (Deploy to Web Hosting)
ท่านสามารถนำโฟลเดอร์ `ระบบสอบออนไลน์` นี้ขึ้นสู่ระบบออนไลน์ เพื่อให้นักเรียนทำข้อสอบจากที่บ้านหรือในห้องเรียนผ่านอินเทอร์เน็ตได้ฟรีตลอดชีพ:
- **GitHub Pages:** สร้าง Repository บน GitHub แล้วเปิดฟังก์ชัน Pages เลือกชี้มาที่โฟลเดอร์นี้
- **Vercel / Netlify:** ลากโฟลเดอร์นี้ไปวางบนเว็บ [vercel.com](https://vercel.com) หรือ [netlify.com](https://netlify.com) จะได้ลิงก์เว็บไซต์สำหรับสอบทันที

## 👨‍🏫 4. คู่มือสำหรับอาจารย์ผู้สอน (Teacher Dashboard & Administration)

### การเข้าสู่หน้าแดชบอร์ดอาจารย์
1. ที่แถบเมนูด้านบนขวาของหน้าเว็บ คลิกที่ปุ่ม **⚙️ แดชบอร์ดครู**
2. ระบบจะถามรหัสผ่าน (Admin PIN) ให้กรอก: `1234`
3. ท่านจะเข้าสู่หน้าต่างสรุปผลการสอบของนักศึกษาทั้งหมด

### ฟังก์ชันสำคัญในแดชบอร์ด:
- **ดูประวัติการส่งข้อสอบ:** แสดงชื่อ-นามสกุล, รหัสนักศึกษา, วิชาที่สอบ, คะแนนปรนัย (เต็ม 30), จำนวนครั้งที่สลับหน้าจอ, และเวลาที่ส่ง
- **ส่งออกคะแนนเป็นไฟล์ Excel/CSV (ปุ่ม "📥 ดาวน์โหลด CSV"):** ดาวน์โหลดไฟล์ตารางคะแนนเพื่อนำไปตัดเกรดลงในระบบ ศธ.02 หรือสมุดบันทึกคะแนนของ วก.เบตง
- **ตั้งค่าส่งคะแนนเข้า Google Sheets อัตโนมัติ (Webhook):**
  1. สร้าง Google Sheets ขึ้นมา 1 ไฟล์
  2. ไปที่ ส่วนขยาย ➜ Apps Script
  3. วางโค้ด Webhook Receiver (ดูโค้ดตัวอย่างในหัวข้อที่ 5 ด้านล่าง)
  4. กด Deploy เป็น Web App (สิทธิ์: Anyone) แล้วนำ URL ที่ได้มาวางในช่อง "Google Sheets Webhook URL" ในแดชบอร์ด
  5. เมื่อนักเรียนทุกคนกดส่งข้อสอบ คะแนนจะวิ่งเข้าบันทึกใน Google Sheets โดยอัตโนมัติแบบเรียลไทม์!

## 🔗 5. โค้ด Google Apps Script สำหรับรับคะแนนเข้า Google Sheets (Webhook Receiver)

หากต้องการให้ผลสอบวิ่งเข้าสู่ Google Sheets โดยอัตโนมัติ ให้สร้าง Apps Script ใน Google Sheets แล้ววางโค้ดนี้:

```javascript
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    
    // สร้างหัวตารางอัตโนมัติหากยังไม่มี
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        'วันที่ส่ง', 'รหัสวิชา', 'ชื่อวิชา', 'รหัสนักศึกษา', 
        'ชื่อ-นามสกุล', 'ระดับชั้น', 'คะแนนปรนัย (30)', 
        'เวลาที่ใช้', 'สลับแท็บ(ครั้ง)'
      ]);
      sheet.getRange(1, 1, 1, 9).setFontWeight('bold').setBackground('#dbeafe');
    }
    
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.submittedAt,
      data.courseCode,
      data.courseName,
      data.studentId,
      data.studentName,
      data.studentLevel,
      data.mcScore,
      data.timeSpent,
      data.strikes
    ]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: 'success' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: 'error', message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

## 📝 6. วิธีใช้งานสคริปต์สร้าง Google Forms อัตโนมัติ 5 รายวิชา

ในกรณีที่อาจารย์ต้องการสร้างเป็น Google Forms สำรอง:
1. เปิดไฟล์ `สร้าง_Google_Forms_อัตโนมัติ.js` ในโฟลเดอร์นี้ แล้วกดคัดลอกโค้ดทั้งหมด (Ctrl+A ➜ Ctrl+C)
2. ไปที่ [Google Apps Script Dashboard](https://script.google.com/) แล้วกด **"โครงการใหม่" (New Project)**
3. วางโค้ดทับในไฟล์ `Code.gs`
4. ที่แถบเครื่องมือด้านบน เลือกฟังก์ชัน **`createAllExamForms`** แล้วกดปุ่ม **"เรียกใช้" (Run)**
5. กดยอมรับสิทธิ์การเข้าถึง Google Drive
6. รอประมาณ 1-2 นาที ระบบจะสร้าง Google Forms ข้อสอบครบทั้ง 5 ชุด พร้อมคีย์เฉลยและกำหนดคะแนน 35 ข้อปรนัย + 3 ข้ออัตนัย ลงใน Google Drive ของอาจารย์ทันที
7. ลิงก์ข้อสอบจะแสดงขึ้นมาในหน้าต่าง "บันทึกการประมวลผล (Execution Log)" สามารถคัดลอกส่งให้นักเรียนได้เลย!
